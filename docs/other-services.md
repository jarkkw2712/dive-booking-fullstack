# ค่าบริการอื่น ๆ

- รายการแต่ละรายการเก็บแยกจากยอด Booking เดิมที่รายงานใช้ จำนวนเงินเป็น numeric(14,2) ส่วนหน้าสรุป Booking บวกค่าบริการเพื่อแสดงยอดรวมให้พนักงาน
- รายงานทุกชนิดยังใช้ข้อมูลและยอดเดิม ไม่รวมบริการอื่น ๆ จนกว่าจะมีข้อกำหนดใหม่ ใบพิมพ์ Booking แสดงเฉพาะเอกสารที่เลือกไว้กับแต่ละรายการ และ Invoice ใหม่สามารถรวมค่าบริการโดยไม่แก้ Invoice ที่ออกแล้ว
- การบันทึกรายการใหม่ แก้ไข หรือลบใช้ transaction เดียวกับ Booking และมี revision ป้องกันการเขียนทับจากหน้าที่เปิดค้าง รายการที่ลบถูกปิดใช้งาน ไม่ hard-delete และการเปลี่ยนแปลงบันทึกใน Audit Log
- ค่าเริ่มต้นเอกสารตั้งใน Master Data ใช้กับรายการที่เพิ่มใหม่เท่านั้น การเปลี่ยนค่าเริ่มต้นไม่เปลี่ยนรายการ Booking ที่บันทึกแล้ว

## ติดตั้งและย้อนกลับ

รัน `supabase/migrations/20261108055023_booking_other_services.sql` ก่อน deploy backend แล้วจึง deploy frontend ตรวจสิทธิ์และการบันทึกในสภาพแวดล้อมทดสอบก่อนใช้งานจริง อย่าลบตารางหรือ audit เมื่อย้อนระบบ

เมื่อมีข้อมูลบริการแล้ว หากต้องย้อนกลับไปใช้ backend/frontend รุ่นเก่า ให้หยุดแก้ Booking ที่มีค่าบริการและเก็บสำรองข้อมูลก่อน เนื่องจากรุ่นเก่าไม่แสดงรายการเหล่านี้ รายงานต่าง ๆ จะไม่รวมค่าบริการตามข้อกำหนดปัจจุบัน จนกว่าจะพัฒนาการรวมรายงานในรุ่นถัดไป
